# AlertaJá — Global Solution 2026/2

Protótipo acadêmico que apresenta informações **fictícias** sobre alagamentos, consulta por bairro, registro demonstrativo de ocorrência e orientações de segurança. **Não é um serviço oficial de emergência** e não possui integração com fontes reais ou backend.

## Tecnologias

- HTML5 semântico, CSS3 com Flexbox e Media Queries, JavaScript puro (DOM e eventos).
- Sem bibliotecas e frameworks de Front-End.

## Como executar

1. Baixe e extraia o projeto mantendo todas as pastas.
2. Abra `index.html` no navegador.
3. Navegue pelo menu para acessar as outras seis páginas.
4. Teste o filtro por bairro na página Mapa, o cadastro demonstrativo e o contato.

## Estrutura

```text
index.html

assets/icone.svg
assets/captura-inicio.png
README.md
IDENTIFICACAO.txt
```

## Interações

1. Menu mobile abre/fecha com JavaScript.
2. Filtro do mapa por bairro (Penha, Tatuapé e Itaquera) e botões de marcador.
3. Registro demonstrativo com validação, classificação ilustrativa do risco e feedback.
4. Formulário de contato com Nome, E-mail, Assunto e Mensagem, validação e erro por campo.
5. FAQ em formato acordeão.
